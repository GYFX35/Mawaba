# Contributing to Mawaba

Thank you for your interest in contributing to **Mawaba**! Mawaba is a global platform for interaction, business integration, climate solutions, global culture, educational AI, and social development ideas.

We welcome contributions of all kinds—bug fixes, new features, documentation improvements, UI enhancements, and security updates.

---

## Code of Conduct

By participating in this project, you agree to abide by our [Code of Conduct](CODE_OF_CONDUCT.md). Please report unacceptable behavior to the project maintainers.

---

## Project Architecture & Structure

Mawaba is structured as a monorepo containing multiple applications:

- **`apps/frontend`**: Next.js React frontend with Tailwind CSS (`http://localhost:3000`)
- **`apps/backend`**: Express Node.js & TypeScript API server (`http://localhost:3001`)
- **`apps/ai-service`**: Python AI service for AI Tutor & Gemini/OpenAI integrations
- **`packages/*`**: Shared monorepo packages

## Getting Started

### Prerequisites

- **Node.js**: v20 or later
- **npm**: v10 or later
- **Python**: v3.12 or later (for `apps/ai-service`)
- **Git**

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/mawaba/mawaba.git
   cd mawaba
   ```

2. Install Node.js dependencies for the root and all workspaces:
   ```bash
   npm install
   ```

3. Set up the Python virtual environment (optional/recommended for AI service):
   ```bash
   pip install -r apps/ai-service/requirements.txt
   ```

### Running Locally

- **Start Frontend**:
  ```bash
  npm run dev --workspace=frontend
  ```
- **Start Backend**:
  ```bash
  npm run dev --workspace=backend
  ```
- **Run AI Service**:
  ```bash
  python3 apps/ai-service/main.py
  ```

## How to Contribute

### 1. Reporting Bugs

Before creating a bug report, search existing issues to see if it has already been reported. If not, open a new issue using our **[Bug Report Template](.github/ISSUE_TEMPLATE/bug_report.yml)**.

Include:
- Clear title and summary
- Affected component (`apps/frontend`, `apps/backend`, `apps/ai-service`, etc.)
- Reproducible steps
- Expected vs actual behavior

### 2. Requesting Features

Have an idea to improve Mawaba? Use our **[Feature Request Template](.github/ISSUE_TEMPLATE/feature_request.yml)** to share your ideas, mockups, or suggestions.

### 3. Submitting Pull Requests

1. **Fork & Branch**: Create a feature branch from `main`:
   ```bash
   git checkout -b feature/your-feature-name
   # or
   git checkout -b fix/your-bug-fix
   ```
2. **Make Changes**: Follow code style guidelines and write tests for new functionality.
3. **Run Tests Locally**: Verify that all test suites pass before opening a PR:
   - Backend Tests: `npm test --workspace=backend`
   - AI Service Tests: `PYTHONPATH=apps/ai-service python3 -m unittest apps/ai-service/test_main.py`
   - Frontend Lint: `npm run lint --workspace=frontend`
   - Frontend Build: `npm run build --workspace=frontend`
4. **Commit**: Use descriptive commit messages following Conventional Commits (e.g., `feat: add climate CO2 calculator`, `fix: resolve auth state bug`).
5. **Open Pull Request**: Submit your PR using the [Pull Request Template](.github/PULL_REQUEST_TEMPLATE.md).

## Dependabot & Automated Dependencies

This repository uses **Dependabot** to keep dependencies up to date. Dependabot runs automated weekly checks for:
- npm packages (monorepo root and apps)
- GitHub Actions workflows
- Python packages (`apps/ai-service`)

Pull requests generated by Dependabot are automatically analyzed and tested by our CI workflow.

---

## Testing Guidelines

- Write unit tests for new backend API endpoints in `apps/backend/src/index.test.ts`.
- Write unit tests for new AI service functions in `apps/ai-service/test_main.py`.
- Ensure all CI tests pass cleanly before requesting code review.
