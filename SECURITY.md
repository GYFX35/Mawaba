## Reporting a Vulnerability

We take the security of Mawaba seriously. If you believe you have discovered a security vulnerability in this project, please follow these guidelines to report it responsibly.

### How to Submit a Report

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, please send a detailed security report via email to `security@mawaba.org` (or directly via private vulnerability reporting on GitHub if enabled).

In your report, please include:

1. **Description**: A clear summary of the vulnerability and its potential impact.
2. **Affected Component**: The specific location (e.g. `apps/frontend`, `apps/backend`, `apps/ai-service`, or specific API endpoint).
3. **Reproduction Steps**: Step-by-step instructions or proof-of-concept code to reproduce the issue.
4. **Environment**: Any relevant OS, browser, or environment details.

---

## Response Process

When we receive a security bug report:

1. **Acknowledgment**: We will acknowledge receipt of your report within 48 hours.
2. **Assessment**: Our maintainers will investigate and confirm the vulnerability.
3. **Remediation**: We will prepare a fix and release a security patch in a timely manner.
4. **Disclosure**: Once patched, we will publicly announce the vulnerability with appropriate credit to the reporter.

Thank you for helping keep Mawaba safe and secure for everyone!
